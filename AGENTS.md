# Preferências do projeto

- O usuário quer manter este aplicativo no repositório Git `ThiSouza21/app-promotion-and-offer-chat`.
- Ao concluir alterações solicitadas neste projeto, registre as mudanças em commit e envie ao repositório, salvo orientação posterior em contrário. Use a branch combinada; a publicação inicial está em `main`. Nunca use force push nem sobrescreva trabalho remoto.
- Preserve dados locais e credenciais. Não versione `data/`, arquivos de ambiente com segredos, tokens, bancos locais ou anexos pessoais.
- Mantenha o uso simples no Linux KDE Neon e a portabilidade da pasta entre computadores com Python 3.10+.
- Diferencie testes com respostas simuladas de chamadas reais à OpenAI ou à Meta. Não afirme que a publicação automática em comunidades WhatsApp está pronta enquanto não tiver sido implementada e verificada.
